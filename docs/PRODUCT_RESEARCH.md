# หาสินค้าขายดีสำหรับนายหน้า (Affiliate) — ความรู้ที่ระบบใช้

เอกสารนี้สรุปหลักการเลือกสินค้าที่ระบบสินค้าเทรนด์ (`/trends`) นำมาใช้ เขียนสรุปด้วยคำของเราเองจากหนังสือ
**"คู่มือทำนายหน้า TikTok ด้วย AI เดือนละ 100,000 แบบไม่ออกหน้ากล้อง"** โดย นักเขียนไส้เปียก
(บทว่าด้วย "อะไรคือสินค้าขายดีและการหาสินค้ามาขาย" ประมาณหน้า 38–91) ไม่ใช่การคัดลอกเนื้อหา
ถ้าต้องการรายละเอียดหรือตัวอย่างครบถ้วน ให้อ่านจากหนังสือต้นฉบับ

> ทุกตัวเลขในหน้านี้เป็นการประเมินคร่าว ๆ หนังสือย้ำว่า **ไม่มีสูตรตายตัว** ระบบจึงแสดงเหตุผลประกอบทุกครั้ง
> และให้คนตัดสินใจขั้นสุดท้าย

---

## 1. "สินค้ากระแส" ไม่เท่ากับ "สินค้าขายดี"

- สินค้าที่กำลังเป็นกระแสคือสินค้าที่ยอดขายพุ่งอยู่ตอนนี้ แต่กระแสมีวันหมด
- สินค้าที่เห็นว่าขายดีที่สุดในหมวด มักเป็นสินค้าที่มีคนทำคลิปขายเต็มตลาดแล้ว ถ้าเพิ่งเริ่มทำตอนนี้ก็จะได้ส่วนแบ่งน้อย
- เป้าหมายของนายหน้าคือหาสินค้าที่ **กำลังจะเป็นกระแส** แล้วเข้าไปก่อนตลาดอิ่มตัว

## 2. วงจรชีวิตสินค้า 10 ระยะ

ยอดขายของสินค้าส่วนใหญ่เป็นเส้นโค้งรูประฆัง หนังสือแบ่งออกเป็น 10 ระยะ

| ระยะ | ความหมาย | สำหรับนายหน้า |
|---|---|---|
| Phase 1 | เพิ่งเริ่มมีคนซื้อ | เร็วไป ความต้องการยังไม่ชัด |
| Phase 2 | เริ่มเป็นกระแส | รับได้ |
| **Phase 3** | ความต้องการโตเร็ว คนทำคลิปยังไม่เยอะ | **ดีที่สุด** |
| Phase 4 | ใกล้ถึงจุดสูงสุด | รับได้ ต้องทำเร็ว |
| Phase 5 | เกือบอิ่มตัว | เสี่ยง |
| A | จุดสูงสุด ตลาดอิ่มตัว | ไม่แนะนำ |
| B–E | ความต้องการลดลงเรื่อย ๆ | ไม่แนะนำ |

## 3. อย่าเลือกอันดับ 1–10 ของหมวด

สินค้าที่ติดอันดับ 1–10 ในหน้า "สินค้ายอดนิยม" (30 วัน) ของหมวด มักอยู่ช่วงจุดสูงสุดหรือขาลงแล้ว และมีคนทำคลิปขายจำนวนมาก
ให้มองหาสินค้า **อันดับ 11 ลงไป** ที่ยอดขายกำลังขึ้น

## 4. ประเมิน Phase แบบคร่าว ๆ

1. ดูยอดขายของสินค้าอันดับ 1 และ 2 ของหมวด แล้วหาค่าเฉลี่ย ใช้เป็น "ยอดสูงสุดของหมวด"
2. เทียบยอดขายของสินค้าที่สนใจกับตัวเลขนั้น — สินค้าที่ขายได้ราว **25–35%** ของยอดสูงสุดถือว่าอยู่ใน Phase 3
3. ดูยอด "ขายแล้วเมื่อเดือนที่แล้ว" ประกอบ ถ้ายอดขายรวมสูงใกล้ยอดสูงสุดของหมวด แต่ยอดรายเดือนลดลงชัดเจน แปลว่าเลยจุดสูงสุดไปแล้ว

ตัวอย่างในหนังสือ (ตัวเลขโดยประมาณ):

| สินค้า | ขายแล้ว | ยอดสูงสุดของหมวด | สัดส่วน | ผลประเมิน |
|---|---|---|---|---|
| เสื้อยืด | 29,000 | 100,000 | 29% | Phase 2–3 |
| กล่องเก็บเครื่องประดับ | 11,000 | 200,000 | 5.5% | Phase 2–3 |
| กล่องใส่รองเท้า | 3,300 | 200,000 | 1.65% | Phase 1–2 |
| ชั้นวางของ | 23,000 | 25,000 | 92% | ยอดเดือนล่าสุดเหลือราว 3,151 ชิ้น → เลยจุดสูงสุดแล้ว |

## 5. เช็กลิสต์ 9 ข้อก่อนเลือกสินค้า

1. สินค้าอยู่ใน Phase 3
2. ดาวสินค้าเฉลี่ย 4.5 ขึ้นไป
3. รีวิวส่วนใหญ่เป็นเชิงบวก
4. มีรีวิวที่เป็นภาพถ่ายหรือวิดีโอจริงจากผู้ซื้อ
5. คะแนนร้าน 4.5 ขึ้นไป
6. อัตราการตอบกลับแชต 75% ขึ้นไป
7. จัดส่งภายใน 48 ชั่วโมง 65% ขึ้นไป
8. ค่าคอมมิชชัน 8% ขึ้นไป
9. มีแฟลชเซลอย่างต่อเนื่อง (ช่วยให้คนดูตัดสินใจซื้อง่าย)

## 6. เลือกสินค้าจากตัวตนของช่อง

- ช่องที่ขายสินค้าตรงกับชีวิตจริงและความชอบของเจ้าของช่องจะเล่าเรื่องได้จริงใจ และทำต่อเนื่องได้นาน
- วิธีในหนังสือ: ให้ AI สวมบทนักวิเคราะห์ครีเอเตอร์ระดับ Top 100 แล้วใส่โปรไฟล์ของเรา (อายุ งาน งานอดิเรก สัตว์เลี้ยง สไตล์ ออกหน้ากล้องได้หรือไม่)
- ให้ AI วางแผนตามลำดับนี้:
  1. คอนเซ็ปต์ช่อง
  2. ชื่อช่อง
  3. รูปแบบคอนเทนต์
  4. เอกลักษณ์
  5. แผนโปรโมต
  6. ตัวอย่างคอนเทนต์
  7. หมวดสินค้าที่ควรขาย

## ระบบนำไปใช้อย่างไร

| หลักการ | ในระบบ | โค้ด |
|---|---|---|
| Phase จากสัดส่วนยอดขาย | สัดส่วน = ขายแล้ว ÷ ยอดสูงสุดของหมวด<br>< 5% → 1 · < 25% → 2 · < 35% → **3** · < 50% → 4 · < 80% → 5 · ≥ 80% → A | `backend/src/modules/scraping/lifecycle.js` → `estimatePhase` |
| ขาลง | ยอดเดือนล่าสุด ÷ เดือนก่อน (ถ้าไม่มี ใช้ความเร็วยอดขายจาก snapshot แบบเฉลี่ย 3 ช่วง เทียบกับช่วงที่ดีที่สุด)<br>< 75% → B · < 50% → C · < 25% → D · < 10% → E | `estimatePhase` |
| ยอดสูงสุดของหมวด | อัตโนมัติ = ค่าเฉลี่ยยอดขายอันดับ 1–2 ที่ระบบเก็บได้ (ต้องมี ≥ 3 รายการในหมวด)<br>ถ้ารู้ตัวเลขจริงจากแอปให้กรอกเอง ค่าที่กรอกเองมีผลเหนือค่าอัตโนมัติ | `trend_category_benchmarks`, `PUT /api/scraping/benchmarks` |
| อันดับ 1–10 | ป้าย "อิ่มตัว" บนการ์ด, ตัวกรอง "ซ่อนอันดับ 1–10", คะแนนเหมาะทำ × 0.6 | `pickScore` |
| เช็กลิสต์ 9 ข้อ | แต่ละข้อมีสถานะ ผ่าน / พอใช้ (Phase 2, 4) / ไม่ผ่าน / ยังไม่มีข้อมูล<br>ข้อที่ไม่มีข้อมูลไม่นับว่าตก และติ๊กตรวจเองได้ | `evaluateChecklist` |
| คะแนน "เหมาะทำนายหน้า" 0–100 | ครึ่งหนึ่งจาก Phase (3 = เต็ม, 2/4 = 75%), อีกครึ่งจากเช็กลิสต์ 8 ข้อที่เหลือ (ไม่มีข้อมูล = กลาง ๆ)<br>เป็นค่าเรียงเริ่มต้นของหน้า `/trends` | `pickScore` |
| คะแนนเทรนด์เดิม | ยังคงไว้เพื่อวัด "แรงกระแส" (ความเร็วยอดขาย) แยกจาก "ควรเลือกไหม" | `score.js` |
| โปรไฟล์ช่อง | หน้า `/trends/channel`: AI (MiniMax) วางแนวช่องตามลำดับในหนังสือ<br>คีย์เวิร์ดของแต่ละหมวดกดสร้างแหล่งข้อมูล Shopee Affiliate ได้ทันที<br>โปรไฟล์หลักถูกส่งไปให้ AI ตอนวิเคราะห์สินค้า (`channelFit`) | `channel_profiles`, `/api/scraping/channel-profiles` |
| AI วิเคราะห์สินค้า | prompt ใส่ Phase, เหตุผล, อันดับ, ผลเช็กลิสต์ และโปรไฟล์ช่อง<br>บอกหลัก "Phase 2–4" และ "อันดับ 11 ขึ้นไป" | `POST /api/scraping/trends/:id/analyze` |

### ข้อจำกัด

- ยอดสูงสุดอัตโนมัติคิดจากสินค้าที่ระบบเก็บได้เท่านั้น ซึ่งอาจไม่ใช่อันดับ 1–2 จริงของทั้งตลาด ถ้ารู้ตัวเลขจริงควรกรอกเอง
- ความเร็วยอดขายจาก snapshot ต้องเก็บข้อมูลอย่างน้อยราว 5 วัน (ห่างกันวันละครั้ง) จึงจะประเมินขาลงได้
- เกณฑ์ช่วงสัดส่วนปรับให้ตรงกับตัวอย่างในหนังสือ ไม่ได้ทดสอบกับข้อมูลตลาดจริงจำนวนมาก
