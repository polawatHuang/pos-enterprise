# POS Enterprise

ระบบบริหารร้านค้าแบบครบวงจรสำหรับองค์กร ครอบคลุม POS, สต๊อก, บัญชีและภาษี, Unified Inbox พร้อม AI ปิดการขาย, AI Video, ตั้งเวลาโพสต์ + Affiliate และ Smart Dashboard

| โปรเจกต์ | Stack | Deploy |
|---|---|---|
| [`frontend/`](frontend) | Next.js 16 · React 19 · Tailwind v4 · TanStack Query | **Vercel** |
| [`backend/`](backend) | Node.js 22 · Express 5 · MySQL | **Plesk (Atom Hosting)** |
| [`database/`](database) | `schema.sql` + `seed.sql` | import ผ่าน **phpMyAdmin** |

สองฝั่งเป็นโปรเจกต์อิสระ (ไม่มี shared code) และคุยกันผ่าน REST API เท่านั้น

## รันบนเครื่อง (local)

ต้องมี Node.js 20.11+ และ MySQL 8 / MariaDB 10.6+

```bash
# 1) Database
mysql -u root -e "CREATE DATABASE pos_enterprise CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci"
mysql -u root pos_enterprise < database/schema.sql
mysql -u root pos_enterprise < database/seed.sql

# 2) Backend  → http://localhost:4000/api/health
cd backend
cp .env.example .env        # แก้ DB_* ให้ตรงเครื่อง
npm install
npm run dev

# 3) Frontend → http://localhost:3000
cd ../frontend
cp .env.example .env.local  # BACKEND_URL=http://localhost:4000
npm install
npm run dev
```

เข้าสู่ระบบด้วย `admin@example.com` / `Admin@1234` (ระบบบังคับเปลี่ยนรหัสผ่านครั้งแรก) หรือบัญชีเดโมตามบทบาท `manager@`, `accountant@`, `cashier@`, `marketer@`, `support@`, `viewer@example.com` (รหัสผ่านเดียวกัน)

## ตรวจสอบคุณภาพ

```bash
cd backend  && npm run lint && npm test          # integration tests (ต้องมี DB ที่ import seed แล้ว)
cd frontend && npm run lint && npx tsc --noEmit && npm run build
```

สร้าง `seed.sql` ใหม่ (ข้อมูลเดโมใช้เวลาแบบ relative จึงแสดง "วันนี้" ถูกต้องเสมอ): `node database/tools/generate-seed.js`

## สถานะ

**เฟส 1 (ส่งมอบแล้ว):** โครงสร้างทั้งสองฝั่ง · schema ครบทุกโมดูล · auth + RBAC 8 บทบาท · จัดการผู้ใช้ · layout responsive + dark mode · Smart Dashboard · คิวงานเบื้องหลัง · adapter สำหรับ API ภายนอกทุกเจ้า · คู่มือ deploy

**เฟส 2 (ส่งมอบแล้ว):** จัดการสินค้า + ฐานความรู้ AI · สต๊อกหลายคลัง (รับเข้า/ปรับยอด/โอนย้าย/ประวัติ, ต้นทุนถัวเฉลี่ย) · POS หน้าร้าน (เปิด-ปิดกะ, สแกนบาร์โค้ด, เงินสด/PromptPay QR/บัตร/โอน, ใบเสร็จ 80mm, ยกเลิกบิลพร้อมคืนสต๊อก)

**เฟส 9 — POS รุ่นใหม่ (แบบ 7-Eleven × Wongnai):**
- หน้าขายแบบสแกนก่อน: ปุ่มสินค้าโปรด, หน่วยแพ็ก/ลังที่มีบาร์โค้ดของตัวเอง, พิมพ์ `6*` ก่อนสแกนเพื่อขายทีละ 6
- คีย์ลัด F1–F10: กด F1 ที่หน้าขายเพื่อดูทั้งหมด
- พักบิล / เรียกบิล และแบ่งจ่ายหลายวิธี (เงินสด, PromptPay, บัตร, โอน, e-Wallet)
- PromptPay QR ใส่ยอดอัตโนมัติ และ AI ตรวจสลิป (กันสลิปซ้ำ)
- สมาชิก (ค้นด้วยเบอร์ / สมัครใน 2 ช่อง) พร้อมแต้มสะสมและใช้แต้ม
- จอลูกค้า (`/customer-display`): แสดงรายการ, QR ตัวใหญ่, ยืนยันอายุ 20+ และขอบคุณ
- กฎตามหมวดสินค้า: งดขายตามช่วงเวลา (เช่น แอลกอฮอล์) และสินค้าที่ต้องยืนยันอายุ
- เงินเข้า/ออกลิ้นชัก, นำเงินเข้าตู้เซฟ, ปิดกะด้วยการนับแบงก์/เหรียญ, รายงาน X/Z
- **ตรวจนับสต๊อก** (`/inventory/counts`): สแกนนับด้วยมือถือผ่านกล้องหรือเครื่องสแกน
  - นับแบบไม่เห็นยอดในระบบ และขายต่อได้ระหว่างนับ
  - ผู้จัดการดูรายงานส่วนต่างแล้วอนุมัติ ระบบลงบัญชีสินค้าขาด/เกินให้
- **แจ้งเตือนสต๊อก**
  - แจ้งที่กระดิ่งในแอป และส่ง LINE OA ทันทีเมื่อของหมด
  - ส่งสรุปทุกเช้า: ใกล้หมด / หมด / ขายไม่ออก
  - หน้าสต๊อกแสดงยอดขาย 14 วัน, ขายเฉลี่ยต่อวัน, พอขายอีกกี่วัน และจุดสั่งซื้อแยกคลัง
- **สั่งซื้อ & รับของ** (`/purchasing`)
  - บอร์ดสั่งของแบบ 7-Eleven: การ์ดรายสินค้าแสดงยอดขาย 14 วัน, ของที่มี, ของที่กำลังมา, พอขายอีกกี่วัน และยอดแนะนำ (กด +/- ทีละแพ็ก)
  - ปุ่ม "ให้ AI ปรับตามเทศกาล" (MiniMax) ปรับยอดสั่งตามวันหยุด/วันเงินเดือนออก
  - สร้างใบสั่งซื้อแยกตามผู้ขายในคลิกเดียว พิมพ์ใบสั่งซื้อได้
  - รับของด้วยการสแกน รับบางส่วนได้ ระบบอัปเดตต้นทุนถัวเฉลี่ย
  - โอนย้ายระหว่างสาขาแบบมีสถานะ "ระหว่างทาง" ปลายทางกดรับตามจริง ระบบบันทึกของที่ขาด
  - จัดการผู้ขาย (ระยะเวลาส่งของ)
- **ล็อต / วันหมดอายุ / ของเสีย** (`/inventory/expiry`)
  - สินค้าที่เปิด "ติดตามวันหมดอายุ" ต้องใส่วันหมดอายุตอนรับของ (หรือให้ระบบเติมจากอายุสินค้า)
  - ขายล็อตที่หมดอายุก่อนออกก่อน (FEFO) ล็อตที่หมดอายุแล้วขายไม่ได้
  - กดลดราคา 20/30/50% ได้ในคลิกเดียว หน้าขายลดให้อัตโนมัติพร้อมป้าย "ลด X% ใกล้หมดอายุ"
  - บันทึกของเสียพร้อมเหตุผล (ลงบัญชีให้) และดูรายงานของเสียรายเดือนได้
  - ระบบสั่งของรอบหน้าลดลงตามสัดส่วนที่ทิ้ง และแจ้งเตือนสินค้าใกล้หมดอายุ

**เฟส 3 (ส่งมอบแล้ว):** บัญชีคู่อัตโนมัติ (POS, รายรับ-รายจ่าย, เอกสาร) · รายรับ-รายจ่ายพร้อม VAT/หัก ณ ที่จ่าย · เอกสาร A4 (ใบเสนอราคา, ใบแจ้งหนี้, ใบกำกับภาษี, ใบเสร็จ, ใบลดหนี้, 50 ทวิ) เลขที่ต่อเนื่อง · ร่าง ภ.พ.30 / ภ.ง.ด.3 / ภ.ง.ด.53 + CSV · งบกำไรขาดทุน, งบทดลอง, สมุดรายวัน · AI อ่านใบเสร็จ

  - กรองเฉพาะ Phase 2–4 และซ่อนอันดับ 1–10 ได้

- **AI Video รุ่นใหม่**:
  - **ฟุตเทจของฉัน**: อัปโหลดคลิป/รูปสินค้าจริง แล้ว AI ตัดต่อ ใส่เสียงพากย์ และใส่ซับให้
  - **ซับเด้งทีละคำ**: ตัวใหญ่ ไฮไลต์คำเด่น และอยู่ในพื้นที่ปลอดภัยของ TikTok
  - **ตัดเร็ว**: ช็อตละ 1–2 วินาที รูปนิ่งมีซูม/สไลด์
  - **Hook 3 แบบ**: เลือกใช้ หรือแยกเป็นอีกเวอร์ชันเพื่อทดสอบ
  - **ปก AI เป็นเฟรมแรก**: แสดง 0.5 วินาทีแรกของคลิป
- หน้า **AI ปกคลิป**: เลือกแนวตั้ง/แนวนอน ใส่ style ข้อความ และแนบรูป แล้ว MiniMax ออกแบบและสร้างภาพพื้นหลัง (ไม่มีตัวหนังสือ) ระบบวางหัวข้อภาษาไทยทับให้ แก้ข้อความ ฟอนต์ สี และตำแหน่งได้ทันที ดาวน์โหลด PNG 1080×1920 / 1920×1080
- ปุ่ม **AI ค้นหาสินค้าขายดี**: MiniMax ค้นเว็บหาสินค้ากำลังมาแรงแล้วนำเข้าในคลิกเดียว เก็บเฉพาะรายการที่มีแหล่งอ้างอิงจริง
- AI วิเคราะห์ความเหมาะสม จุดขาย ไอเดียเปิดคลิป และความเสี่ยง
