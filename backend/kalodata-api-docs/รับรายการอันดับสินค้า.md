region	string	
รหัสประเทศของข้อมูล เช่น US, BR, MX, ID, JP, MY, PH, SG, TH, VN, GB, ES, DE, FR, IT, PL, NL, BE, CZ, AT, GR, PT, HU, IE
US	ใช่
language	string	
ภาษาของฟิลด์ข้อความในการตอบสนอง ปัจจุบันรองรับ zh-CN, en-US, id-ID, th-TH, vi-VN, es-ES, ja-JP, pt-BR, ko-KR, fr-FR, de-DE, pl-PL, nl-NL, cs-CZ, el-GR, hu-HU, pt-PT, it-IT
en-US	ใช่
currency	string	
หน่วยสกุลเงินของฟิลด์ยอดขายและราคา ปัจจุบันรองรับ CNY, USD, IDR, VND, THB, MYR, JPY, PHP, GBP, SGD, MXN, EUR, BRL, PLN, CZK, HUF
USD	ใช่
date_range	string	
ช่วงวันที่ ยอมรับช่วงที่มีชื่อ (lastDay, last7Day, last30Day, last60Day, last90Day, last180Day, last365Day), ช่วงวันที่ตามธรรมชาติในรูปแบบ yyyy-MM-dd~yyyy-MM-dd หรือเดือนตามธรรมชาติ yyyy-MM เอ็นด์พอยต์บางรายการจำกัดชุดนี้ — ดูคำอธิบายของแต่ละเอ็นด์พอยต์
last7Day	ใช่
sort_field	object	
ข้อกำหนดการจัดเรียง field รองรับฟิลด์ตัวเลขใดๆ จากการตอบกลับ type คือ ASC หรือ DESC ค่าเริ่มต้นคือ {"field":"revenue","type":"DESC"}
ใช่
field	string	
ชื่อฟิลด์การจัดเรียง รองรับฟิลด์ตัวเลขใดๆ ที่ส่งคืนโดยเอ็นด์พอยต์ (เช่น revenue, sales_volumn, revenue_growth_rate)
revenue	ไม่ใช่
type	string	
ทิศทางการจัดเรียง
DESC	ไม่ใช่
rank_field	string	
ทางลัดแบบเดิมสำหรับชื่อฟิลด์การจัดเรียง แนะนำให้ใช้ sort_field จะถูกละเว้นเมื่อมีการตั้งค่า sort_field
revenue	ไม่ใช่
asc	boolean	
ธงจากน้อยไปมากแบบเดิมที่จับคู่กับ rank_field ค่าเริ่มต้นเป็น false (DESC)
false	ไม่ใช่
page_size	integer	
ขนาดหน้า สูงสุด 100 รายการต่อการค้นหา ค่าเริ่มต้น 10
20	ไม่ใช่
page_number	integer	
หมายเลขหน้า เริ่มต้นที่ 1
1	ไม่ใช่

["601450"]	ไม่ใช่

จำกัดผลลัพธ์เฉพาะร้านค้าที่ระบุ
7495634116320922282	ไม่ใช่
creator_id	string	
จำกัดผลลัพธ์เฉพาะสินค้าที่โปรโมตโดยครีเอเตอร์ที่ระบุ เมื่อรวมกับ shop_id จะส่งคืนรายการของครีเอเตอร์สำหรับร้านค้านั้น
7495634116320922282	ไม่ใช่
video_id	string	
ส่งคืนสินค้าที่แนบมากับวิดีโอที่กำหนด
7495634116320922282	ไม่ใช่
livestream_id	string

7495634116320922282	ไม่ใช่
revenue_range	string	
ตัวกรองช่วงรายได้ ในสกุลเงินเดียวกับสกุลเงินของคำขอ และยังรองรับรูปแบบ <10 / >1 ด้วย
1-10	ไม่ใช่
is_affiliate	integer	
ตัวกรองโปรแกรม Affiliate 0 = ไม่ใช่ Affiliate เท่านั้น, 1 = Affiliate เท่านั้น
1	ไม่ใช่
commission_rate	string	
ตัวกรองอัตราค่าคอมมิชชันสำหรับสินค้า Affiliate รองรับช่วง (15-35), ปลายเปิด (<10, >=30) หรืออัตราส่วนเดียว
15-35	ไม่ใช่
is_tts_product	integer	
ตัวกรองสินค้า TTS (TikTok จัดการเต็มรูปแบบ) 1 = จัดการเต็มรูปแบบเท่านั้น, 0 = จัดส่งเองเท่านั้น
1	ไม่ใช่
unit_price_range	string	
ตัวกรองช่วงราคาต่อชิ้นของสินค้า
1-1000	ไม่ใช่
need_all	boolean	
หากเป็น true จะรวมสินค้าที่ไม่มียอดขายในช่วงเวลาที่เลือก ค่าเริ่มต้นคือ false (เฉพาะสินค้าที่มียอดขายเท่านั้น)
false	ไม่ใช่
delivery_type	string	
ตัวกรองวิธีการจัดส่งสินค้า local = การจัดส่งภายในประเทศ, global = ข้ามพรมแดน
local	ไม่ใช่
launch_date	string	
จำนวนวันตั้งแต่เปิดตัวสินค้า <3 = ภายใน 3 วัน, <7 = ภายใน 7 วัน, >30 = มากกว่า 30 วัน
<7	ไม่ใช่
need_image	integer	
จำเป็นต้องใช้ URL รูปภาพหลักหรือไม่: 0-ไม่จำเป็น (ค่าเริ่มต้น), 1-ส่งคืน URL ทางการ, 2-ส่งคืน URL รูปภาพ kalo_data (ต้องใช้บริการแบบชำระเงิน)
1	ไม่ใช่
keyword	string	
ค้นหาคีย์เวิร์ด
mobile phone	ไม่ใช่

ต้องการข้อมูลเพิ่มเติม เช่น ชื่อผู้ขาย จำนวน SKU
false	ไม่ใช่
