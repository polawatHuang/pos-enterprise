ภาษาของฟิลด์ข้อความในการตอบสนอง ปัจจุบันรองรับ zh-CN, en-US, id-ID, th-TH, vi-VN, es-ES, ja-JP, pt-BR, ko-KR, fr-FR, de-DE, pl-PL, nl-NL, cs-CZ, el-GR, hu-HU, pt-PT, it-IT
en-US	ใช่
currency	string	
หน่วยสกุลเงินของฟิลด์ยอดขายและราคา ปัจจุบันรองรับ CNY, USD, IDR, VND, THB, MYR, JPY, PHP, GBP, SGD, MXN, EUR, BRL, PLN, CZK, HUF
USD	ใช่
date_range	string	
ช่วงวันที่ ยอมรับช่วงที่มีชื่อ (lastDay, last7Day, last30Day, last60Day, last90Day, last180Day, last365Day), ช่วงวันที่ตามธรรมชาติในรูปแบบ yyyy-MM-dd~yyyy-MM-dd หรือเดือนตามธรรมชาติ yyyy-MM เอ็นด์พอยต์บางรายการจำกัดชุดนี้ — ดูคำอธิบายของแต่ละเอ็นด์พอยต์
last7Day	ใช่
sort_field	object	
ข้อกำหนดการจัดเรียง field รองรับฟิลด์ตัวเลขใดๆ จากการตอบกลับ type คือ ASC หรือ DESC ค่าเริ่มต้นคือ {"field":"revenue","type":"DESC"}
ใช่
field	string	
ชื่อฟิลด์การจัดเรียง รองรับฟิลด์ตัวเลขใดๆ ที่ส่งคืนโดยเอ็นด์พอยต์ (เช่น revenue, sales_volumn, revenue_growth_rate)
revenue	ไม่ใช่

ทิศทางการจัดเรียง
DESC	ไม่ใช่

ทางลัดแบบเดิมสำหรับชื่อฟิลด์การจัดเรียง แนะนำให้ใช้ sort_field จะถูกละเว้นเมื่อมีการตั้งค่า sort_field
revenue	ไม่ใช่
asc	boolean	
ธงจากน้อยไปมากแบบเดิมที่จับคู่กับ rank_field ค่าเริ่มต้นเป็น false (DESC)
