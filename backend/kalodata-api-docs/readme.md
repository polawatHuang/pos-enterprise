การสนทนาแต่ละครั้งจะหักคะแนนตามการใช้โทเค็น การสนทนาที่ซับซ้อนมักใช้ประมาณ 10–15 คะแนน ส่วนการสนทนาง่ายๆ ประมาณ 2–5 คะแนน
เมื่อคะแนนหมด ให้คลิกปุ่ม [Top Up] ด้านบนเพื่อเติมเงิน
